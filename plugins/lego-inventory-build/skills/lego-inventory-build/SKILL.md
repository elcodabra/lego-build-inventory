# lego-inventory-build

Движок рисует детали LEGO на Canvas 2D в стиле бумажной инструкции, а инвентарь следит за тем, чтобы модель собиралась из того, что лежит у пользователя в коробке. Модель это JSON со списком шагов, `check-model` проверяет геометрию и наличие деталей, `render` делает ролик.

Главные правила. Только настоящие детали без выдуманной печати. Только детали из инвентаря, а если чего-то не хватает, об этом надо сказать прямо.

## Что лежит в папке

- `src/lego.js` движок, 47 деталей и 34 цвета с id BrickLink и Rebrickable. `src/booklet.js` сценарий ролика.
- `src/models/cat.js`, `microduck.js` примеры моделей. Свои модели храни в `models/<имя>.json` в рабочей папке.
- `lib/core.cjs` модели, проверка, BOM и инвентарь. `lib/film.cjs` рендер через Playwright.
- `tools/inventory.cjs` инвентарь: `import`, `add-set`, `add`, `remove`, `show`, `fit`, `bom`, `clear`.
- `tools/model-json.cjs` печатает любую модель в JSON. `tools/check-model.cjs` проверка геометрии и наличия деталей. `tools/snap.cjs` кадры в PNG, `tools/render.cjs` видео, `tools/mosaic.cjs` портрет-мозаика.
- `reference/modeling.md` координаты и правила сборки. Прочитай перед первой моделью.
- `reference/inventory.md` как наполнять инвентарь и проектировать под него.
- `reference/parts.md` таблица деталей и цветов.
- `mcp/server.mjs` те же возможности как MCP-сервер. Скиллу он не нужен.

## Подготовка

Работай в папке скилла или скопируй ее в проект. Нужны Node.js 20+ и ffmpeg (или путь в `FFMPEG`).

```bash
npm install && npx playwright install chromium
node tools/check-model.cjs cat --no-inv
```

Готово, когда проверка кота зеленая.

Инвентарь, `check-model`, `bom` и `fit` работают на голом Node без `npm install`. Playwright и Chromium нужны только для `snap` и `render`. Если в песочнице нет сети (например, в claude.ai), спроектируй и проверь модель, отдай JSON модели и список деталей, а рендер предложи запустить локально или через MCP-сервер. Данные (инвентарь, сохраненные модели) лежат в `~/.lego-build/` или в `$LEGO_DATA_DIR`, а `./inventory.json` в текущей папке важнее них.

## Как собрать модель из своих деталей

1. **Инвентарь.** Выполни `node tools/inventory.cjs show`. Если пусто, попроси у пользователя номера наборов (`add-set`, нужен `REBRICKABLE_API_KEY`), CSV или экспорт (`import`). Подробности в `reference/inventory.md`. Готово, когда `show` показывает детали, которые рисует движок, и ты знаешь, каких цветов больше всего.
2. **Бриф.** Спроси, что собираем и в какой ориентации ролик. Если пользователь не знает, предложи 2-3 идеи под его палитру: из красного и черного выйдет божья коровка, из серого робот. Готово, когда объект описан одной фразой.
3. **Набросок.** Модель на клетке в двух видах, спереди и сверху. Размер выбирай по запасу основного цвета, палитру бери только из инвентаря. Готово, когда понятно, из каких слоев модель и сколько деталей каждого цвета уйдет.
4. **Модель.** Пиши `models/<имя>.json` в формате `{ "title", "theta", "phi", "steps": [[{ "id", "color", "at": [x,y,z], "rot"?, "up"?, "from"? }]] }`, шаги снизу вверх по `reference/modeling.md`. Пример в том же формате печатает `node tools/model-json.cjs microduck`, разобранный образец с комментариями лежит в `src/models/cat.js`. Готово, когда `node tools/check-model.cjs models/<имя>.json` пишет `no overlaps, everything is held, all parts are in the inventory`.
   - `OVERLAP`/`FLOATS`: поправь координаты.
   - `MISSING`: возьми замену из списка `есть:` или перестрой участок из того, что есть.
5. **Кадры.** Выполни `node tools/snap.cjs 3 8 final --model models/<имя>.json` и посмотри PNG в `exports/`. Проверь, что модель узнается, детали не залезают друг в друга, список деталей помещается. Готово, когда модель узнается в финальном кадре с первого взгляда.
6. **Рендер.** Выполни `node tools/render.cjs --model models/<имя>.json`, для горизонтали добавь `--format horizontal`. Отдай пользователю mp4 и список деталей `node tools/inventory.cjs bom models/<имя>.json`.

Если модель без докупки не выходит, покажи `node tools/inventory.cjs fit models/<имя>.json` и `bom --csv` для wanted list на BrickLink.

## Портрет из фото

`node tools/mosaic.cjs <фото> --name <имя>` собирает мозаику из плиток 1×1 (`--size 64`, `--zoom`, `--dither`, `--contrast`, `--sharpen`, `--frames 3,9`, `--video`). Инвентарь здесь не учитывается: мозаике нужны сотни плиток, их обычно докупают.

## Правила

- Никакой выдуманной печати. Глаза, носы и узоры собирай из простых деталей.
- Детали лица крепи на шипы сбоку (87087), а не просто прикладывай.
- Перед каждым рендером `check-model` должен быть зеленым. Если чего-то не хватает, это допустимо только после того, как пользователь согласился докупить.
- Не называй модель проверенной вживую, если ее никто не собирал руками.
- В коде отрисовки нельзя использовать `Math.random` и `Date`.
- LEGO принадлежит LEGO Group. Не подавай ролик как официальный и не рисуй логотип.

## Если нужной детали нет в движке

Добавь ее в `src/lego.js` помощниками `box`, `slope`, `ridge`, `curve`, `round` с номером BrickLink, затем выполни `node tools/parts-md.cjs`. Подробности в `reference/modeling.md`.
